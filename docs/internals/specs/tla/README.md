# TLA+ Specifications

This directory holds guidance for writing and checking formal specifications of Quickwit protocols. There are currently no checked-in models.

The Parquet data model, sort schema, time-windowed compaction, and Parquet merge lifecycle models were removed with their implementations.

See [the verification guide](../../VERIFICATION.md) for general guidance and [the TLC workflow](./CLAUDE.md) for running future models.
