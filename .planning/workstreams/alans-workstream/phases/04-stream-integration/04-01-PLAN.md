    ```rust
    impl TaskTransform<Event> for MetricMetadataTransform {
        fn transform(
            self: Box<Self>,
            task: Pin<Box<dyn Stream<Item = Event> + Send>>,
        ) -> Pin<Box<dyn Stream<Item = Event> + Send>> {
            let mut input = task;
            let mut known_metrics = self.known_metrics;
            let mut pending = self.pending;
            let flush_client = self.flush_client;
            let config = self.config;
            let persist_path = config.persist_file_path.clone();

            let mut flush_timer =
                tokio::time::interval(Duration::from_secs(config.flush_interval_secs));
            let mut persist_timer =
                tokio::time::interval(Duration::from_secs(config.persist_interval_secs));

            Box::pin(async_stream::stream! {
                loop {
                    tokio::select! {
                        biased;

                        maybe_event = input.next() => {
                            let Some(event) = maybe_event else {
                                // D-06: Shutdown sequence
                                break;
                            };

                            // Per-event: classify metric and accumulate unknowns
                            if let Event::Metric(ref metric) = event {
                                let name = metric.name().to_string();
                                if !known_metrics.contains(&name) {
                                    let type_info = map_metric_type(metric);
                                    // HashMap dedup; last-seen-wins
                                    pending.insert(name, type_info);
                                }
                            }

                            // D-04: batch_size trigger -- flush before yield
                            if pending.len() >= config.batch_size {
                                match flush_client.flush_pending(&pending).await {
                                    Ok(succeeded) => {
                                        for name in succeeded {
                                            known_metrics.insert(name);
                                        }
                                    }
                                    Err(err) => {
                                        warn!(error = %err, "batch-size flush failed, pending metrics dropped");
                                    }
                                }
                                pending.clear();
                                flush_timer.reset(); // D-05: avoid double-flush
                            }

                            yield event; // XFRM-01: pass-through unchanged
                        }

                        _ = flush_timer.tick() => {
                            if !pending.is_empty() {
                                match flush_client.flush_pending(&pending).await {
                                    Ok(succeeded) => {
                                        for name in succeeded {
                                            known_metrics.insert(name);
                                        }
                                    }
                                    Err(err) => {
                                        warn!(error = %err, "interval flush failed, pending metrics dropped");
                                    }
                                }
                                pending.clear();
                            }
                        }

                        _ = persist_timer.tick() => {
                            known_metrics.prune_expired();
                            if let Err(err) = csv_persistence::save_to_csv(
                                Path::new(&persist_path),
                                known_metrics.iter(),
                            ) {
                                warn!(error = %err, "failed to persist known metrics");
                            }
                        }
                    }
                }

                // D-06: Post-loop shutdown sequence
                // Step 1: Flush remaining pending metrics
                if !pending.is_empty() {
                    match flush_client.flush_pending(&pending).await {
                        Ok(succeeded) => {
                            for name in succeeded {
                                known_metrics.insert(name);
                            }
                        }
                        Err(err) => {
                            // D-07: Log and proceed; metrics re-detected after restart
                            warn!(error = %err, "shutdown flush failed, pending metrics dropped");
                        }
                    }
                    pending.clear();
                }

                // Step 2: Prune expired entries
                known_metrics.prune_expired();

                // Step 3: D-08: Always persist CSV on shutdown
                if let Err(err) = csv_persistence::save_to_csv(
                    Path::new(&persist_path),
                    known_metrics.iter(),
                ) {
                    warn!(error = %err, "failed to persist known metrics on shutdown");
                }
            })
        }
    }
    ```

    Key implementation notes:
    - D-01: `tokio::select!` with `biased` inside `async_stream::stream!`. Input events prioritized over timers.
    - D-02: Three branches -- input stream, flush timer, persist timer.
    - D-03: No future recreation. `interval.tick()` returns a new future each call which is the designed usage. No `tokio::sync::Mutex`, no `JoinHandle::abort()`. All state owned by closure.
    - D-04: Batch-size check inline after each event. Flush before yield (per Pitfall 4 from RESEARCH.md).
    - D-05: `flush_timer.reset()` after batch-size triggered flush.
    - D-06: Break on `None`, then flush + prune + persist.
    - D-07: `warn!` on shutdown flush failure, proceed with persist.
    - D-08: Always persist on shutdown unconditionally.
    - First tick of `tokio::time::interval` fires immediately -- the `if !pending.is_empty()` guard on flush and unconditional persist are harmless (Pitfall 1 from RESEARCH.md).
    - All `warn!` messages start lowercase, no trailing punctuation (CLAUDE.md log format).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| transform -> SaaS endpoint | HTTP POST with API key crosses trust boundary to external service |
| input stream -> transform | Untrusted metric events from upstream pipeline enter the transform |
| transform -> filesystem | CSV persistence writes to local disk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | warn! log messages | mitigate | Log messages must not include API key or raw metric data. FlushError Display impl already redacts key. warn! calls use %err format only. |
| T-04-02 | Denial of Service | flush timer / batch_size trigger | accept | Malformed input could generate unbounded pending entries. Mitigated by existing batch_size threshold (default 200) which caps memory before flush. Acceptable risk for internal pipeline. |
| T-04-03 | Tampering | CSV persist file | accept | CSV file is on local disk with OS-level permissions. Atomic rename prevents partial writes. No additional mitigation needed for internal service. |
| T-04-04 | Spoofing | DD-API-KEY header | mitigate | API key validated at build() time (Phase 1, T-01-01). FlushClient holds key without Debug derive (Phase 3, T-01-02). No new exposure in Phase 4. |
| T-04-05 | Elevation of Privilege | select! loop state | accept | All mutable state owned by single closure. No locks, no shared memory, no Mutex (GAP-002). Single-threaded access pattern prevents race conditions. |
</threat_model>
