- A module-private helper function:
  ```rust
  fn now_unix_secs() -> u64 {
      std::time::SystemTime::now()
          .duration_since(std::time::UNIX_EPOCH)
          .expect("system clock is before Unix epoch")
          .as_secs()
  }
  ```
- The `KnownMetrics` struct:
  ```rust
  pub struct KnownMetrics {
      entries: HashMap<String, u64>,  // metric_name -> expiry Unix timestamp (seconds)
      ttl_min_secs: u64,
      ttl_max_secs: u64,
  }
  ```
- Methods on KnownMetrics:
  - `pub fn new(ttl_min_hours: u64, ttl_max_hours: u64) -> Self` -- creates empty map, converts hours to seconds
  - `pub fn contains(&self, name: &str) -> bool` -- delegates to `self.entries.contains_key(name)`. Per D-09: does NOT check expiry. Expired entries are still "known" until prune_expired() sweeps them.
  - `pub fn insert(&mut self, name: String)` -- computes `now_unix_secs() + rand::rng().random_range(self.ttl_min_secs..=self.ttl_max_secs)` and inserts into entries
  - `pub fn prune_expired(&mut self)` -- calls `let now = now_unix_secs(); self.entries.retain(|_name, expiry| *expiry > now);` per D-08
  - `pub fn iter(&self) -> impl Iterator<Item = (&str, u64)>` -- returns `self.entries.iter().map(|(k, v)| (k.as_str(), *v))`
  - `pub fn len(&self) -> usize` -- returns `self.entries.len()`
  - `pub fn is_empty(&self) -> bool` -- returns `self.entries.is_empty()`
  - `pub fn load_entries(&mut self, entries: HashMap<String, u64>)` -- replaces `self.entries` with the provided map. Used by build() to load CSV data at startup.
