<objective>
Implement CSV persistence (atomic load/save) and wire KnownMetrics + pending list into the transform.

Purpose: This plan delivers the persistence layer and the transform integration that together make the metric metadata tracking functional. After this plan, the transform can load known metrics from CSV on startup, classify incoming metrics as known/unknown, accumulate unknowns into a pending list with dedup, and save the known set back to CSV atomically. The persist tick timer and flush cycle are Phase 3/4 concerns -- this plan provides the callable functions and the per-event logic.

Output: `csv_persistence.rs` with load/save functions, updated `mod.rs` with KnownMetrics and pending fields on the transform struct, CSV loading in build(), and per-event known/unknown classification in the transform stream. All covered by unit tests.

**Step 2: Create `csv_persistence.rs`** with:

- License header (Apache 2.0, "Copyright 2021-Present Datadog, Inc.")
- Imports:
  ```rust
  use std::collections::HashMap;
  use std::io::{BufRead, BufReader, Write};
  use std::path::Path;

  use tempfile::NamedTempFile;
  use tracing::warn;
  ```
- Constant: `const CSV_HEADER: &str = "metric_name,expiry_ts";`
- `pub fn load_from_csv(path: &Path) -> anyhow::Result<HashMap<String, u64>>`:
  - Open file with `std::fs::File::open(path)`. Match on result:
    - `Ok(f)` -> proceed
    - `Err(err) if err.kind() == std::io::ErrorKind::NotFound` -> return `Ok(HashMap::new())` (per D-04)
    - `Err(err)` -> return `Err(err.into())`
  - Create `BufReader::new(file)` and iterate with `reader.lines().enumerate()`
  - For each `(line_number, line_result)`:
    - If `line_result` is `Err(err)`: `warn!(line_number, error=%err, "skipping unreadable CSV line");` continue
    - If `line_number == 0 && line.trim() == CSV_HEADER`: continue (skip header per D-03)
    - Split with `line.split_once(',')`:
      - `None` -> `warn!(line_number, line=%line, "skipping malformed CSV line: no comma");` continue
      - `Some((name, ts_str))` -> parse `ts_str.trim().parse::<u64>()`
        - `Err(err)` -> `warn!(line_number, value=%ts_str.trim(), error=%err, "skipping malformed CSV line: invalid timestamp");` continue
        - `Ok(expiry_ts)` -> `entries.insert(name.trim().to_string(), expiry_ts);`
  - Return `Ok(entries)`

- `pub fn save_to_csv(path: &Path, entries: impl Iterator<Item = (&str, u64)>) -> anyhow::Result<()>`:
  - Compute parent dir: `let parent = path.parent().unwrap_or(Path::new("."));`
  - Create temp file: `let mut temp_file = NamedTempFile::new_in(parent)?;`
  - Write header: `writeln!(temp_file, "{}", CSV_HEADER)?;` (per D-03)
  - Write entries: `for (name, expiry_ts) in entries { writeln!(temp_file, "{},{}", name, expiry_ts)?; }` (per D-02)
  - Flush: `temp_file.flush()?;`
  - Atomic rename: `temp_file.persist(path)?;` (per D-05)
  - Return `Ok(())`

**Step 4: Update TaskTransform::transform()** -- Replace the current pass-through with known/unknown classification:
```rust
impl TaskTransform<Event> for MetricMetadataTransform {
    fn transform(
        self: Box<Self>,
        task: Pin<Box<dyn Stream<Item = Event> + Send>>,
    ) -> Pin<Box<dyn Stream<Item = Event> + Send>> {
        let mut known_metrics = self.known_metrics;
        let mut pending = self.pending;

        Box::pin(task.map(move |event| {
            if let Event::Metric(ref metric) = event {
                let name = metric.name().to_string();
                if !known_metrics.contains(&name) {
                    let type_info = map_metric_type(metric);
                    // D-06: HashMap dedup; D-07: last-seen-wins
                    pending.insert(name, type_info);
                }
            }
            event
        }))
    }
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CSV file -> KnownMetrics | Operator-controlled file path; contents parsed line-by-line with malformed row tolerance |
| Metric events -> pending list | Events from trusted upstream pipeline (Datadog Agent / OTel); metric names follow [a-zA-Z][a-zA-Z0-9_.]* |
| tempfile -> final CSV path | Same-directory creation ensures no cross-filesystem rename failure |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Tampering | CSV file content | accept | File is operator-controlled; malformed rows skipped with warning; no code execution from CSV data |
| T-02-05 | Tampering | Metric names in pending list | accept | Names come from trusted Datadog Agent pipeline; comma-free by Datadog naming rules (A1 assumption) |
| T-02-06 | Denial of Service | Malformed CSV causing load failure | mitigate | Per-row parsing with skip-on-error (D-04); only total file I/O error causes build() failure |
| T-02-07 | Denial of Service | Partial CSV write visible to readers | mitigate | tempfile-then-rename atomic write pattern (D-05, PERSIST-02); readers see old file or new file, never partial |
| T-02-08 | Information Disclosure | Metric names in CSV file | accept | Metric names are not PII; file path and permissions are operator-controlled |
</threat_model>
