# Milestone v0.1: Alpha

**Status:** SHIPPED 2026-01-15
**Phases:** 1-10
**Total Plans:** 23

## Overview

Replace Tantivy with DataFusion/Parquet for metrics workloads in Quickwit. Starting with core infrastructure, then building storage, ingest, and query layers before integrating with the existing actor pipeline and search system. The project maintains full compatibility with Tantivy for logs/traces while providing a high-throughput columnar engine for metrics.

## Milestone Summary

**Key Decisions:**
- DataFusion 45 for Arrow 54 compatibility (version alignment)
- Zstd level 3 default compression (balanced speed/ratio)
- 128K rows per row group (efficient columnar scans)
- Index name prefix routing (automatic pipeline selection)
- SQL generation for MVP (QueryAst translation deferred)

**Issues Resolved:**
- DataFusion/Arrow version compatibility
- Parquet feature naming (snap vs snappy)
- Source trait type constraints (MetricsSourceActor adapter)
- Storage URI path access (filepath() method)

**Issues Deferred:**
- Percentile aggregations
- Full QueryAst to SQL translation

**Technical Debt Incurred:**
- is_metrics_index() duplicated in search and indexing crates
- Simplified SQL generation (not full QueryAst translation)
