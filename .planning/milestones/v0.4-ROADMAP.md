```bash
make test-metrics-e2e

# Stop infrastructure

```

## Key Decisions

1. **Use minio-init one-shot container:** Separate bucket creation from minio service to avoid --wait issues
2. **Feature gate postgres:** Use `cfg(feature = "postgres")` to keep testsuite lightweight
3. **Graceful skip when infra unavailable:** Tests check infrastructure availability and skip gracefully
