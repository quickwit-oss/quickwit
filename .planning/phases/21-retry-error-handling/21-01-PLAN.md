Create error.rs module with MetricsIngestError enum. Follow the SubworkbenchFailure pattern from workbench.rs.

Error variants (classified by retryability):

**Permanent errors (NOT retryable):**
- `IndexNotFound` - Index doesn't exist in metastore
- `SourceNotFound` - Source doesn't exist
- `InvalidMetricsData` - Malformed metrics that can't be processed

**Transient errors (retryable):**
- `WalFull` - WAL capacity exhausted, retry after backpressure clears
- `IoError(io::Error)` - Temporary disk/network issues
- `MetastoreUnavailable(String)` - Metastore temporarily unreachable
- `InternalError(String)` - Catchall for transient internal issues
- `Timeout` - Operation timed out

Implement:
1. `MetricsIngestError` enum with Display and Error traits
2. `Retryable` trait from quickwit-common (import and implement `is_retryable()`)
3. Helper methods: `is_retryable(&self) -> bool`, `into_retry(self) -> Retry<Self>`

Pattern from workbench.rs to follow:
```rust
fn last_failure_is_transient(&self) -> bool {
    match self.last_failure_opt {
        Some(SubworkbenchFailure::IndexNotFound) => false,
        Some(SubworkbenchFailure::SourceNotFound) => false,
        Some(SubworkbenchFailure::Internal) => true,  // transient
        Some(SubworkbenchFailure::Unavailable) => true,
        Some(SubworkbenchFailure::RateLimited(_)) => true,
        None => true,
    }
}
```
