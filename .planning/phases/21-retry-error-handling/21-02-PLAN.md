<task type="auto">
  <name>Task 2: Add integration tests for startup recovery scenarios</name>
  <files>quickwit/quickwit-ingest/src/metrics/recovery.rs</files>
  <action>
Add comprehensive tests in recovery.rs #[cfg(test)] mod tests:

1. **test_recovery_empty_wal** - Fresh start with no queues
   - Create new state with empty WAL
   - Call recover_from_wal()
   - Assert: num_recovered_shards = 0, num_deleted_empty_queues = 0

2. **test_recovery_non_empty_queue** - Normal recovery
   - Write 10 records to queue "metrics/idx/src/shard1"
   - Drop state (simulate restart)
   - Create new state with same WAL directory
   - Call recover_from_wal()
   - Assert: num_recovered_shards = 1, shard position matches

3. **test_recovery_truncated_queue** - Recovery with partial truncation
   - Write 20 records to queue
   - Truncate at position 10
   - Drop and recreate state
   - Call recover_from_wal()
   - Assert: truncation_position_inclusive = Position::offset(9)

4. **test_recovery_empty_queue_deleted** - Cleanup of empty queues
   - Create queue but write no records (or truncate all)
   - Drop and recreate state
   - Call recover_from_wal()
   - Assert: num_deleted_empty_queues = 1, queue no longer exists

5. **test_recovery_multiple_queues** - Multiple shards
   - Write to 3 different queues with varying record counts
   - Drop and recreate state
   - Call recover_from_wal()
   - Assert: all 3 shards recovered with correct positions

Use pattern from state.rs tests (create_test_state helper, tempdir for WAL).
