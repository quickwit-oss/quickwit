**1. Create migration 26 up:**

File: `quickwit/quickwit-metastore/migrations/postgresql/26_add-compaction-metadata.up.sql`

```sql
-- Add compaction metadata columns to metrics_splits table.
-- These columns enable compaction scope queries (which splits belong to the same
-- time window with the same sort schema) and store per-split compaction statistics.

ALTER TABLE metrics_splits
    ADD COLUMN IF NOT EXISTS window_start BIGINT,
    ADD COLUMN IF NOT EXISTS window_duration_secs INTEGER,
    ADD COLUMN IF NOT EXISTS sort_schema TEXT NOT NULL DEFAULT '',
    ADD COLUMN IF NOT EXISTS num_merge_ops INTEGER NOT NULL DEFAULT 0,
    ADD COLUMN IF NOT EXISTS row_keys BYTEA,
    ADD COLUMN IF NOT EXISTS zonemap_regexes JSONB NOT NULL DEFAULT '{}';

-- Composite index for compaction scope queries:
-- "Give me all Published splits for (index_id, sort_schema, window_start)"
-- This is the primary query pattern for the compaction planner (Phase 35).
CREATE INDEX IF NOT EXISTS idx_metrics_splits_compaction_scope
    ON metrics_splits (index_id, sort_schema, window_start)
    WHERE split_state = 'Published';
```

Column type rationale (per research + Claude's discretion):
- `window_start BIGINT` -- Nullable for pre-Phase-31 splits. Seconds since epoch.
- `window_duration_secs INTEGER` -- Nullable. 32-bit sufficient (max 3600).
- `sort_schema TEXT NOT NULL DEFAULT ''` -- Empty string for old splits. Indexable.
- `num_merge_ops INTEGER NOT NULL DEFAULT 0` -- Always 0 for new ingested splits.
- `row_keys BYTEA` -- Nullable. Opaque proto bytes per locked decision.
- `zonemap_regexes JSONB NOT NULL DEFAULT '{}'` -- JSONB for future SQL queries.

Add a function to convert MetricsSplitMetadata compaction fields into Parquet key_value_metadata entries:

```rust
use base64::Engine as _;
use base64::engine::general_purpose::STANDARD as BASE64;

/// Build Parquet key_value_metadata entries for compaction metadata.
/// Returns Vec<KeyValue> that can be added to WriterProperties.
pub fn build_compaction_key_value_metadata(
    metadata: &MetricsSplitMetadata,
) -> Vec<parquet::format::KeyValue> {
    let mut kvs = Vec::new();

    if !metadata.sort_schema.is_empty() {
        kvs.push(parquet::format::KeyValue {
            key: PARQUET_META_SORT_SCHEMA.to_string(),
            value: Some(metadata.sort_schema.clone()),
        });
    }

    if let Some(ws) = metadata.window_start {
        kvs.push(parquet::format::KeyValue {
            key: PARQUET_META_WINDOW_START.to_string(),
            value: Some(ws.timestamp().to_string()),
        });
    }

    if metadata.window_duration_secs > 0 {
        kvs.push(parquet::format::KeyValue {
            key: PARQUET_META_WINDOW_DURATION.to_string(),
            value: Some(metadata.window_duration_secs.to_string()),
        });
    }

    if metadata.num_merge_ops > 0 {
        kvs.push(parquet::format::KeyValue {
            key: PARQUET_META_NUM_MERGE_OPS.to_string(),
            value: Some(metadata.num_merge_ops.to_string()),
        });
    }

    if let Some(ref row_keys_bytes) = metadata.row_keys_proto {
        // Canonical: base64-encoded proto bytes
        kvs.push(parquet::format::KeyValue {
            key: PARQUET_META_ROW_KEYS.to_string(),
            value: Some(BASE64.encode(row_keys_bytes)),
        });
        // Debug: human-readable JSON (best-effort -- decode proto, serialize as JSON)
        // The RowKeys proto must be decoded to produce JSON. If decode fails, skip JSON key.
        if let Ok(row_keys) = prost::Message::decode(row_keys_bytes.as_slice()) {
            let row_keys: sortschema::RowKeys = row_keys;
            if let Ok(json) = serde_json::to_string(&row_keys) {
                kvs.push(parquet::format::KeyValue {
                    key: PARQUET_META_ROW_KEYS_JSON.to_string(),
                    value: Some(json),
                });
            }
        }
    }

    kvs
}
```

Integrate this into the existing writer flow. Find where `WriterProperties::builder()` is called and add `.set_key_value_metadata(Some(kvs))` or merge with existing metadata. If the writer already has key_value_metadata, extend rather than replace.
