<task type="auto">
  <name>Task 2: Create AggregateQuery builder for metrics aggregations</name>
  <files>quickwit/quickwit-metrics-engine/src/query/aggregation.rs</files>
  <action>
Create an aggregation module with type-safe query builder:

1. Define AggregateFunction enum: Sum, Avg, Min, Max, Count, Percentile(f64), ApproxPercentile(f64)
   - Implement to_sql() for each variant using DataFusion built-in functions:
     - Sum → "SUM(value)"
     - Avg → "AVG(value)"
     - Min → "MIN(value)"
     - Max → "MAX(value)"
     - Count → "COUNT(*)"
     - Percentile(p) → "PERCENTILE_CONT(p) WITHIN GROUP (ORDER BY value)"
     - ApproxPercentile(p) → "APPROX_PERCENTILE_CONT(value, p)"

2. Define AggregateQuery struct with builder pattern:
   ```rust
   pub struct AggregateQuery {
       table_name: String,
       aggregates: Vec<(AggregateFunction, String)>,  // (function, alias)
       group_by: Vec<String>,
       time_bucket: Option<TimeBucket>,
       filters: Vec<String>,
       time_range: Option<TimeRange>,
   }
   ```

3. Builder methods:
   - aggregate(func, alias) - add aggregation
   - group_by(column) - add grouping column
   - with_time_bucket(bucket) - enable time-series bucketing
   - filter(condition) - add WHERE clause
   - time_range(range) - filter by TimeRange

4. build_sql() method that constructs complete SQL:
   - SELECT clause with aggregates and group_by columns
   - FROM table_name
   - WHERE clause combining filters and time_range
   - GROUP BY clause with time bucket if specified
   - ORDER BY time_bucket if present

Include tests for:
- Simple aggregation (SELECT AVG(value) FROM metrics)
- Grouped aggregation (GROUP BY metric_name)
- Time-bucketed aggregation (GROUP BY time_bucket, metric_name)
- Filtered aggregation (WHERE metric_name = 'cpu.usage')
- Combined filters with time range
  </action>

  <done>AggregateQuery builder generating valid DataFusion SQL for metrics aggregations</done>
