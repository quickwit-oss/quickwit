```rust
pub struct MetricsBatchAccumulator {

    pending_rows: usize,
    pending_bytes: usize,
}

impl MetricsBatchAccumulator {
    pub fn new(config: MetricsIngestConfig, base_path: impl Into<PathBuf>) -> Self { ... }

    /// Add a RecordBatch to the accumulator.
    /// If thresholds are exceeded, flushes to create split(s).
    /// Returns list of splits produced (empty if none flushed).
    pub fn add_batch(&mut self, batch: RecordBatch) -> Result<Vec<MetricsSplit>, IngestError> { ... }

    /// Force flush all pending batches to create split.
    /// Returns None if no pending data.
    pub fn flush(&mut self) -> Result<Option<MetricsSplit>, IngestError> { ... }

    /// Returns current pending row count.
    pub fn pending_rows(&self) -> usize { ... }

    /// Returns current pending byte estimate.
    pub fn pending_bytes(&self) -> usize { ... }
}
```

Implementation notes:
- Byte estimation: Use `batch.get_array_memory_size()` for each batch
- Concatenate batches using `arrow::compute::concat_batches` before writing to split
- After flush, reset pending_batches, pending_rows, pending_bytes to zero
- add_batch may produce 0, 1, or multiple splits depending on incoming batch size
