<task type="auto">
  <name>Task 2: Create MetricsIndexer actor</name>
  <files>quickwit/quickwit-indexing/src/actors/metrics_indexer.rs</files>
  <action>
Create MetricsIndexer actor that:

1. Implements Actor trait (similar to Indexer)
2. Contains MetricsBatchAccumulator from quickwit-metrics-engine
3. Handles ProcessedMetricsBatch messages:
   - Add RecordBatch to accumulator via add_batch()
   - Check for produced splits
   - Forward completed splits to Packager for upload
4. Handles checkpoint/commit messages similar to Indexer
5. On shutdown, flushes remaining accumulated data

Key structures:
```rust
pub struct MetricsIndexer {
    index_id: IndexId,
    accumulator: MetricsBatchAccumulator,
    packager_mailbox: Mailbox<Packager>,
    counters: MetricsIndexerCounters,
    // ... checkpoint handling fields
}
```

Critical: When a MetricsSplit is produced, it needs to be wrapped in a format compatible with the existing Packager actor, or we need to create a message that Packager can handle. For now, create a MetricsSplitBatch message type that carries the split info.

The MetricsIndexer should:
- Initialize with output directory for split files
- Track metrics: rows indexed, splits produced, bytes written
- Support force_commit to flush accumulator immediately
  </action>
