  <files>quickwit/quickwit-indexing/src/actors/metrics_doc_processor.rs</files>
  <action>
Create MetricsDocProcessor actor that:

1. Implements Actor trait (like DocProcessor)
2. Handles RawDocBatch messages containing Arrow IPC data
3. Uses MetricsIngestProcessor from quickwit-metrics-engine to convert Arrow IPC to RecordBatch
4. Forwards RecordBatch to MetricsIndexer (created in Plan 02) via mailbox
5. Tracks processing counters (valid docs, errors) similar to DocProcessor
6. Uses is_arrow_ipc() check to validate incoming data

Key structures:
```rust
pub struct MetricsDocProcessor {
    processor: MetricsIngestProcessor,
    indexer_mailbox: Mailbox<MetricsIndexer>,
    counters: Arc<MetricsDocProcessorCounters>,
    publish_lock: PublishLock,
}
```

The MetricsIndexer type can be forward-declared or use a generic Mailbox for now - it will be created in Plan 02.

Pattern to follow: See DocProcessor for Actor/Handler trait implementations, queue capacity, runtime handle, finalize behavior.

Do NOT attempt to convert Arrow to Tantivy documents - that's the old path. This actor works exclusively with RecordBatch.
