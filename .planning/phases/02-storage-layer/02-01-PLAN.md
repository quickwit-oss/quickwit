   - `ParquetWriterConfig` struct with:
     - `compression: Compression` - compression algorithm
     - `compression_level: Option<i32>` - for zstd (1-22, default 3)
     - `row_group_size: usize` - rows per row group (default 128K)
     - `data_page_size: usize` - bytes per data page (default 1MB)
     - `write_batch_size: usize` - rows per write batch (default 64K)
   - `impl Default for ParquetWriterConfig` with production defaults
   - `impl ParquetWriterConfig` methods:
     - `to_writer_properties(&self) -> WriterProperties` - convert to parquet WriterProperties

Use parquet crate's WriterProperties, WriterPropertiesBuilder, Compression types.
Zstd level 3 is a good balance of speed/ratio for metrics workloads.
Row group size 128K is good for columnar scan efficiency.
