Create MetricsSplitWriter that produces complete MetricsSplit with metadata:

1. Create `src/storage/split_writer.rs` with:
   - `MetricsSplitWriter` struct with:
     - `writer: MetricsParquetWriter`
     - `base_path: PathBuf` - directory for split files
   - Constructor `new(schema: MetricsSchema, config: ParquetWriterConfig, base_path: impl Into<PathBuf>) -> Self`
   - Method `write_split(&self, batch: &RecordBatch) -> Result<MetricsSplit, MetricsWriteError>`:
     - Generate SplitId
     - Create Parquet filename: `{split_id}.parquet`
     - Write batch to file using MetricsParquetWriter
     - Extract time range from batch (min/max timestamp_secs)
     - Extract distinct metric names from batch
     - Build MetricsSplitMetadata with:
       - split_id
       - time_range from batch data
       - num_rows from batch
       - size_bytes from file write result
       - metric_names extracted from batch
       - parquet_files with relative path
     - Return MetricsSplit::new(metadata)

   Helper functions needed:
   - `extract_time_range(batch: &RecordBatch) -> TimeRange` - get min/max of timestamp_secs column
   - `extract_metric_names(batch: &RecordBatch) -> HashSet<String>` - get distinct values from metric_name column

2. Update `src/storage/mod.rs` to export split_writer module

Use Arrow's compute functions (min, max) for time range extraction.
Use dictionary decoding for metric_name column (it's dictionary-encoded).
