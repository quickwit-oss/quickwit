Create MetricsUploader actor following the Uploader pattern from uploader.rs.

Structure:
```rust
pub struct MetricsUploader {
    uploader_type: UploaderType,  // Reuse existing enum
    metastore: MetastoreServiceClient,
    split_store: Arc<dyn Storage>,  // Direct Storage, not IndexingSplitStore (simpler for Parquet)
    split_update_mailbox: MetricsSplitsUpdateMailbox,
    max_concurrent_uploads: usize,
    counters: MetricsUploaderCounters,
}
```

Key components:

1. **MetricsSplitsUpdateMailbox** - Similar to SplitsUpdateMailbox:
```rust
pub enum MetricsSplitsUpdateMailbox {
    // For indexing pipeline: ordered publishing via Sequencer
    Sequencer(Mailbox<Sequencer<Publisher>>),
    // For merge pipeline: direct to Publisher
    Publisher(Mailbox<Publisher>),
}
```

Note: Initially just support Publisher variant since Sequencer integration needs more work in Phase 16.

2. **Handler<MetricsSplitBatch>**:
   - Acquire upload semaphore (use same CONCURRENT_UPLOAD_PERMITS_INDEX)
   - Call stage_metrics_splits() with MetricsSplitMetadata
   - Upload each Parquet file to storage (split_store.put())
   - Create MetricsSplitsUpdate and send downstream
   - Release semaphore

3. **Counters**:
```rust
pub struct MetricsUploaderCounters {
    pub num_staged_splits: Arc<AtomicU64>,
    pub num_uploaded_splits: Arc<AtomicU64>,
}
```

Use StageMetricsSplitsRequestExt::try_from_splits_metadata() to build the request.

For Parquet upload, the file path in MetricsSplit.metadata.parquet_files gives the local filename. Upload to storage with the split_id as the key:
```rust
let parquet_path = output_dir.join(&parquet_filename);
let bytes = tokio::fs::read(&parquet_path).await?;
split_store.put(Path::new(&format!("{}.parquet", split_id)), PutPayload::from(bytes)).await?;
```

Add to actors/mod.rs:
- mod metrics_uploader;
- pub use metrics_uploader::{MetricsUploader, MetricsUploaderCounters, MetricsSplitsUpdateMailbox};
