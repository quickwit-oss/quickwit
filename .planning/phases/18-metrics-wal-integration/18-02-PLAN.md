       ```rust

           &self,
           requested_capacity: ByteSize,
       ) -> Result<(), NotEnoughCapacityError>
       ```
       - Uses self.config.disk_capacity and self.config.memory_capacity
       - Checks mrecordlog.resource_usage() against limits
       - Returns NotEnoughCapacityError::Disk or ::Memory as appropriate
       - Same logic as mrecordlog_utils::check_enough_capacity

    2. Add `force_delete_queue` function:
       ```rust
       /// Deletes a queue, ignoring MissingQueue errors.
       pub async fn force_delete_queue(&self, queue_id: &str) -> io::Result<()>
       ```
       - Acquires write lock
       - Calls delete_queue
       - Returns Ok(()) for both Ok and MissingQueue error
       - Returns Err only for IoError

    3. Add `queue_position_range` function:
       ```rust
       /// Returns first and last position of records in queue, or None if empty/missing.
       pub fn queue_position_range(&self, queue_id: &str) -> Option<RangeInclusive<u64>>
       ```
       - Gets first position via range().next()
       - Gets last position via last_record()
       - Returns None if queue missing or empty

    4. Add `list_metrics_queues` function:
       ```rust
       /// Returns iterator over queue IDs that start with "metrics/" prefix.
       pub fn list_metrics_queues(&self) -> impl Iterator<Item = &str>
       ```
       - Filters list_queues() by METRICS_QUEUE_PREFIX

    5. Add error type at module level (or use existing if compatible):
       ```rust
       #[derive(Debug, Clone, Copy, thiserror::Error)]
       pub enum NotEnoughCapacityError {

           #[error("metrics WAL memory full: capacity {capacity}, usage {usage}, requested {requested}")]
       ```
