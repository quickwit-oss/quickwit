    3. Create `metrics/metrics_wal.rs` with:
       - `MetricsWalConfig` struct with fields:
         - `wal_dir_path: PathBuf` (ADR-1: separate directory for metrics)
         - `disk_capacity: ByteSize`
         - `memory_capacity: ByteSize`

       - `MetricsWal` struct holding:
         - `mrecordlog: Arc<RwLock<MultiRecordLogAsync>>`
         - `config: MetricsWalConfig`

       - Implement MetricsWal methods matching MultiRecordLogAsync API:
         - `pub async fn open(config: MetricsWalConfig) -> Result<Self, ReadRecordError>`
           - Creates MultiRecordLogAsync at config.wal_dir_path
           - Uses PersistPolicy::Always(PersistAction::Flush) like logs pipeline

         - `pub async fn create_queue(&self, queue_id: &str) -> Result<(), CreateQueueError>`
           - Acquires write lock on mrecordlog
           - Calls mrecordlog.create_queue(queue_id)

         - `pub async fn delete_queue(&self, queue_id: &str) -> Result<(), DeleteQueueError>`
           - Acquires write lock on mrecordlog
           - Calls mrecordlog.delete_queue(queue_id)

         - `pub async fn append_records<T>(&self, queue_id: &str, position_opt: Option<u64>, payloads: T) -> Result<Option<u64>, AppendError>`
           where T: Iterator<Item = impl Buf> + Send + 'static
           - Acquires write lock on mrecordlog
           - Calls mrecordlog.append_records(queue_id, position_opt, payloads)

         - `pub async fn truncate(&self, queue_id: &str, position: u64) -> Result<usize, TruncateError>`
           - Acquires write lock on mrecordlog
           - Calls mrecordlog.truncate(queue_id, position)

         - `pub fn range<R>(&self, queue_id: &str, range: R) -> Result<impl Iterator<Item = Record<'_>> + '_, MissingQueue>`
           - Uses mrecordlog_ref() pattern for read access
           - Note: This requires blocking read — acceptable for read-only ops

         - `pub fn queue_exists(&self, queue_id: &str) -> bool`

         - `pub fn list_queues(&self) -> impl Iterator<Item = &str>`
           - Returns all queues (caller filters by metrics/ prefix)

         - `pub fn resource_usage(&self) -> ResourceUsage`

       - `use crate::mrecordlog_async::MultiRecordLogAsync;`
