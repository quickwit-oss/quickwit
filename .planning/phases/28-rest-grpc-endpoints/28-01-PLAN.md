# Plan 28-01: Split Planning Protobuf & Service Method

## Objective

Add protobuf messages and a SearchService method for the `plan_metrics_splits` endpoint that returns splits and their node assignments.

## Context

This endpoint enables external orchestration:
1. External client calls `plan_metrics_splits` with a SearchRequest
2. Quickwit uses existing pruning logic to find relevant splits
3. Response contains splits + nodes that can serve each split
4. External client then calls leaf nodes directly with SQL + splits

**Key insight:** Reuse existing `SearchRequest` — don't parse SQL at root. The SearchRequest already has time range, index patterns, and filters for pruning.

## Tasks

### Task 1: Add protobuf messages

Add planning messages to search.proto.

**File:** `quickwit/quickwit-proto/protos/quickwit/search.proto`

**Add:**
```protobuf
// Request to plan splits for metrics SQL execution.
// Reuses SearchRequest for all pruning (time range, index, filters).
message PlanMetricsSplitsRequest {
  // The search request used for split pruning.
  // Uses: index_id_patterns, start_timestamp, end_timestamp, query_ast
  SearchRequest search_request = 1;
}

// A split assigned to one or more nodes for execution.
message SplitAssignment {
  // Split metadata for leaf execution.
  SplitIdAndFooterOffsets split = 1;
  
  // Storage URI for the index (needed by leaf to access storage).
  string index_uri = 2;
  
  // Node IDs that can serve this split.
  // External orchestrator should pick one (or try multiple for redundancy).
  repeated string node_ids = 3;
}

// Response with split assignments for metrics SQL execution.
message PlanMetricsSplitsResponse {
  // Splits with their node assignments.
  repeated SplitAssignment split_assignments = 1;
  
  // Total number of splits.
  uint32 num_splits = 2;
  
  // Planning time in microseconds.
  uint64 elapsed_micros = 3;
}
```

### Task 5: Implement in SearchServiceImpl

Implement the planning logic.

**File:** `quickwit/quickwit-search/src/service.rs`

```rust
async fn plan_metrics_splits(
    &self,
    request: PlanMetricsSplitsRequest,
) -> crate::Result<PlanMetricsSplitsResponse> {
    let start = Instant::now();
    let mut search_request = request.search_request;
    
    // Use existing split planning logic
    let (split_metadatas, indexes_meta) = plan_splits_for_root_search(
        &mut search_request,
        &mut self.metastore.clone(),
    ).await?;
    
    // Convert to SplitAssignments with node info
    let split_assignments = self.create_split_assignments(
        split_metadatas,
        &indexes_meta,
    ).await?;
    
    Ok(PlanMetricsSplitsResponse {
        num_splits: split_assignments.len() as u32,
        split_assignments,
        elapsed_micros: start.elapsed().as_micros() as u64,
    })
}
```

### Task 6: Implement node assignment helper

Create helper to assign nodes to splits.

**File:** `quickwit/quickwit-search/src/service.rs`

```rust
impl SearchServiceImpl {
    async fn create_split_assignments(
        &self,
        split_metadatas: Vec<SplitMetadata>,
        indexes_meta: &IndexesMetaForLeafSearch,
    ) -> crate::Result<Vec<SplitAssignment>> {
        let mut assignments = Vec::with_capacity(split_metadatas.len());
        
        for split in split_metadatas {
            // Get index URI from metadata
            let index_uri = indexes_meta
                .get_index_uri(&split.index_uid)
                .ok_or_else(|| SearchError::Internal("missing index URI".into()))?;
            
            // Get nodes that can serve this split (use cluster topology)
            let node_ids = self.cluster_client
                .get_nodes_for_split(&split.split_id)
                .await?;
            
            assignments.push(SplitAssignment {
                split: SplitIdAndFooterOffsets::from(&split),
                index_uri: index_uri.to_string(),
                node_ids,
            });
        }
        
        Ok(assignments)
    }
}
```
