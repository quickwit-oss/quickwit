# Plan 28-02: gRPC Adapter for Split Planning

## Objective

Expose the `PlanMetricsSplits` RPC via gRPC so external orchestrators can call it.

## Context

The gRPC endpoint enables:
- ClickHouse to call Quickwit for split planning
- Custom orchestrators to plan before calling leaf nodes
- Standard gRPC client libraries to integrate

This follows existing patterns in `GrpcSearchAdapter`.

## Tasks

### Task 1: Add method to GrpcSearchAdapter

Implement the gRPC handler for PlanMetricsSplits.

**File:** `quickwit/quickwit-serve/src/search_api/grpc_adapter.rs`

**Add:**
```rust
impl search_service_server::SearchService for GrpcSearchAdapter {
    // ... existing methods ...
    
    async fn plan_metrics_splits(
        &self,
        request: Request<PlanMetricsSplitsRequest>,
    ) -> Result<Response<PlanMetricsSplitsResponse>, Status> {
        let request = request.into_inner();
        
        let response = self.search_service
            .plan_metrics_splits(request)
            .await
            .map_err(|e| convert_to_grpc_status(e))?;
        
        Ok(Response::new(response))
    }
}
```

### Task 3: Add SearchServiceClient method

Add client-side method for calling the RPC.

**File:** `quickwit/quickwit-search/src/client.rs`

**Add:**
```rust
impl SearchServiceClient {
    pub async fn plan_metrics_splits(
        &mut self,
        request: PlanMetricsSplitsRequest,
    ) -> crate::Result<PlanMetricsSplitsResponse> {
        match &mut self.client_impl {
            SearchServiceClientImpl::Grpc(grpc_client) => grpc_client
                .plan_metrics_splits(request)
                .await
                .map(|r| r.into_inner())
                .map_err(|e| parse_grpc_error(&e)),
            SearchServiceClientImpl::Local(service) => {
                service.plan_metrics_splits(request).await
            }
        }
    }
}
```

```rust
#[tokio::test]
async fn test_plan_metrics_splits_grpc() {
    // Start test searcher
    let channel = /* connect to test server */;
    let mut client = SearchServiceClient::new(channel);
    
    // Create request with time range
    let request = PlanMetricsSplitsRequest {
        search_request: Some(SearchRequest {
            index_id_patterns: vec!["otel-metrics-*".to_string()],
            start_timestamp: Some(1705000000),
            end_timestamp: Some(1705100000),
            ..Default::default()
        }),
    };
    
    // Call
    let response = client.plan_metrics_splits(request).await?;
    
    // Verify
    assert!(response.num_splits > 0);
    assert!(!response.split_assignments.is_empty());
    for assignment in &response.split_assignments {
        assert!(!assignment.node_ids.is_empty());
        assert!(!assignment.index_uri.is_empty());
    }
}
```
