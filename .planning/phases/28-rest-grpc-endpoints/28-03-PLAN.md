# Plan 28-03: REST Endpoint for Split Planning

## Objective

Create the REST endpoint `POST /api/v1/metrics/plan-splits` that returns split assignments for external orchestration.

## Context

The REST API provides an HTTP alternative to gRPC for split planning:
- POST with JSON body containing search parameters
- Response is JSON with splits and node assignments
- Simple to call from scripts, curl, HTTP clients

Create the request type (simplified from full SearchRequest).

**File:** `quickwit/quickwit-serve/src/metrics_sql_api/rest_handler.rs`

```rust
use serde::{Deserialize, Serialize};
use utoipa::ToSchema;

/// Request body for split planning.
#[derive(Debug, Clone, Deserialize, Serialize, ToSchema)]
pub struct PlanSplitsApiRequest {
    /// Index ID patterns to match (e.g., ["otel-metrics-*"])
    pub index_id_patterns: Vec<String>,
    
    /// Start timestamp for time range pruning (seconds since epoch)
    #[serde(default)]
    pub start_timestamp: Option<i64>,
    
    /// End timestamp for time range pruning (seconds since epoch)
    #[serde(default)]
    pub end_timestamp: Option<i64>,
    
    /// Optional query AST for additional filtering (JSON string)
    #[serde(default)]
    pub query_ast: Option<String>,
}

/// Response with split assignments.
#[derive(Debug, Clone, Serialize, ToSchema)]
pub struct PlanSplitsApiResponse {
    pub split_assignments: Vec<SplitAssignmentApi>,
    pub num_splits: u32,
    pub elapsed_micros: u64,
}

#[derive(Debug, Clone, Serialize, ToSchema)]
pub struct SplitAssignmentApi {
    pub split_id: String,
    pub index_uri: String,
    pub node_ids: Vec<String>,
    /// Footer offsets for split loading
    pub split_footer_start: u64,
    pub split_footer_end: u64,
}
```

### Task 3: Implement POST handler

Create the warp handler.

**File:** `quickwit/quickwit-serve/src/metrics_sql_api/rest_handler.rs`

```rust
use std::sync::Arc;
use warp::{Filter, Rejection, Reply};

pub fn plan_splits_handler(
    search_service: Arc<dyn SearchService>,
) -> impl Filter<Extract = (impl Reply,), Error = Rejection> + Clone {
    warp::path!("api" / "v1" / "metrics" / "plan-splits")
        .and(warp::post())
        .and(warp::body::json())
        .and(with_search_service(search_service))
        .and_then(plan_splits_post_handler)
}

async fn plan_splits_post_handler(
    request: PlanSplitsApiRequest,
    search_service: Arc<dyn SearchService>,
) -> Result<impl Reply, Rejection> {
    // Convert REST request to proto SearchRequest
    let search_request = SearchRequest {
        index_id_patterns: request.index_id_patterns,
        start_timestamp: request.start_timestamp,
        end_timestamp: request.end_timestamp,
        query_ast: request.query_ast.unwrap_or_default(),
        ..Default::default()
    };
    
    let proto_request = PlanMetricsSplitsRequest {
        search_request: Some(search_request),
    };
    
    // Call service
    let response = search_service
        .plan_metrics_splits(proto_request)
        .await
        .map_err(|e| warp::reject::custom(SearchApiError::from(e)))?;
    
    // Convert to API response
    let api_response = PlanSplitsApiResponse {
        split_assignments: response.split_assignments
            .into_iter()
            .map(|a| SplitAssignmentApi {
                split_id: a.split.split_id,
                index_uri: a.index_uri,
                node_ids: a.node_ids,
                split_footer_start: a.split.split_footer_start,
                split_footer_end: a.split.split_footer_end,
            })
            .collect(),
        num_splits: response.num_splits,
        elapsed_micros: response.elapsed_micros,
    };
    
    Ok(warp::reply::json(&api_response))
}
```

#[tokio::test]
async fn test_plan_splits_rest() {
    let client = reqwest::Client::new();
    
    let response = client
        .post("http://localhost:7280/api/v1/metrics/plan-splits")
        .json(&json!({
            "index_id_patterns": ["otel-metrics-*"],
            "start_timestamp": 1705000000,
            "end_timestamp": 1705100000
        }))
        .send()
        .await?;
    
    assert_eq!(response.status(), 200);
    
    let body: PlanSplitsApiResponse = response.json().await?;
    assert!(body.num_splits >= 0);
}
