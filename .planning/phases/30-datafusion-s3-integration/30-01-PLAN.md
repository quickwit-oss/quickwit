  <action>
    Create storage_bridge.rs implementing object_store::ObjectStore by delegating to quickwit_storage::Storage.

    Key implementation details:

    1. StorageObjectStoreAdapter struct holds Arc<dyn Storage>

    2. Implement required ObjectStore methods:
       - `get(&self, location: &Path) -> GetResult` - Use storage.get_all() or storage.get_slice_stream()
       - `get_range(&self, location: &Path, range: Range<usize>) -> Bytes` - Use storage.get_slice()
       - `head(&self, location: &Path) -> ObjectMeta` - Use storage.file_num_bytes() for size
       - `list(&self, prefix: Option<&Path>) -> BoxStream<Result<ObjectMeta>>` - Use storage.list()
       - `list_with_delimiter(&self, prefix: Option<&Path>)` - Use storage.list()

    3. For write operations (put, delete, copy, rename), return NotSupported error since this is read-only for queries.

    4. Convert object_store::path::Path to std::path::Path for storage calls.

    5. Handle async properly - Storage trait methods are async.

    Error mapping:
    - StorageError -> object_store::Error
    - Use object_store::Error::Generic for mapping

    Add to mod.rs:
    ```rust
    mod storage_bridge;
    pub use storage_bridge::StorageObjectStoreAdapter;
    ```

    Include unit tests using quickwit_storage::RamStorage for testing the adapter.
  </action>

  </verify>
