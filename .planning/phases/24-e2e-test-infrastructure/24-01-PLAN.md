   - `cleanup_test_index(metastore, index_id)` - deletes test index after test completion

3. **Environment detection:**
   - Read `QW_S3_ENDPOINT` (default http://localhost:9000)
   - Read `AWS_ACCESS_KEY_ID` (default minioadmin)
   - Read `AWS_SECRET_ACCESS_KEY` (default minioadmin)
