# Plan 27-03: Arrow IPC Serialization Module

## Objective

Create a dedicated Arrow IPC serialization module with utilities for converting DataFusion results to Arrow IPC format, including streaming support for large result sets.

## Context

Arrow IPC (Inter-Process Communication) is the standard format for serializing Arrow data:
- **Streaming format**: Schema → RecordBatch* → End
- **Self-describing**: Schema included in output
- **Efficient**: Zero-copy possible, columnar layout preserved
- **Compatible**: pyarrow, polars, DuckDB, ClickHouse can all read it

This module provides clean utilities for serialization that will be used by both the leaf service (Phase 27) and root service (Phase 28).
