# Plan 27-02: MetricsSqlLeafService Implementation

## Objective

Implement the MetricsSqlLeafService that executes SQL queries on provided splits using DataFusion and returns results as Arrow IPC.

## Context

The leaf service receives SQL + splits from the root coordinator. It:
1. Gets storage for the index
2. Loads split metadata for each provided split
3. Registers splits with DataFusion session
4. Executes the SQL query
5. Serializes results as Arrow IPC
6. Returns response with stats

**Key constraint:** No metastore access. Splits are provided by root.

### Task 3: Implement split loading logic

Load MetricsSplit metadata for each provided split ID.

**Logic:**
1. Get storage from storage_resolver for index URI
2. For each split in request:
   - Call `load_metrics_split(storage, split_id)` (existing function in metrics_leaf.rs)
   - Collect into Vec<MetricsSplit>
3. Handle partial failures — track which splits failed to load

**Reference:** `quickwit/quickwit-search/src/metrics_leaf.rs` — `load_metrics_split` function

### Task 4: Implement DataFusion execution

Register splits and execute SQL.

**Logic:**
1. Create `MetricsSessionContext::new(config)`
2. Determine base_path from storage
3. Call `ctx.register_splits(table_name, &splits, base_path)`
4. Execute SQL: `ctx.sql(&request.sql).await`
5. Collect results: `df.collect().await`

**Table name:** Extract from SQL or use index ID directly

### Task 5: Convert results to Arrow IPC

Serialize RecordBatches to Arrow IPC format.

**Logic:**
1. Get schema from first batch
2. Use `arrow::ipc::writer::StreamWriter` to write:
   - Schema message
   - RecordBatch messages
3. Return bytes

**Reference:** Arrow crate documentation for IPC streaming format

### Task 6: Build response with stats

Construct MetricsSqlLeafResponse with all required fields.

**Fields:**
- `arrow_ipc`: Serialized Arrow IPC bytes
- `num_rows`: Total rows across all batches
- `elapsed_micros`: Execution time
- `failed_splits`: Any splits that failed to load/query
- `num_successful_splits`: Count of successfully processed splits

### Task 7: Add error types

Create error enum for leaf service operations.

**File:** `quickwit/quickwit-metrics-engine/src/sql/mod.rs`

```rust
#[derive(Debug, thiserror::Error)]
pub enum MetricsSqlError {
    #[error("Storage error: {0}")]
    Storage(String),
    
    #[error("DataFusion error: {0}")]
    DataFusion(#[from] datafusion::error::DataFusionError),
    
    #[error("Arrow IPC error: {0}")]
    ArrowIpc(#[from] arrow::error::ArrowError),
    
    #[error("Split load error for {split_id}: {message}")]
    SplitLoad { split_id: String, message: String },
}
```
