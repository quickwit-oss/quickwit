# Plan 27-01: Protobuf Definitions for MetricsSqlLeaf

## Objective

Define protobuf messages for the MetricsSqlLeaf service that accepts SQL queries with pre-assigned splits and returns Arrow IPC responses.

## Context

The MetricsSqlLeafService is the worker node that receives SQL + splits from the root coordinator. This plan creates the protobuf interface that mirrors the existing `LeafSearchRequest`/`LeafSearchResponse` pattern but for direct SQL execution with Arrow IPC responses.

**Key design decisions:**
- Leaf receives splits from root — no metastore access
- Reuse existing `SplitIdAndFooterOffsets` message for split references
- Arrow IPC bytes returned as opaque `bytes` field
- Error reporting per-split for partial failure handling

## Tasks

### Task 1: Create metrics_sql.proto

Create the protobuf file with leaf-specific messages.

**File:** `quickwit/quickwit-proto/protos/quickwit/metrics_sql.proto`

**Messages to define:**
- `MetricsSqlLeafRequest` — SQL query + splits + index info
- `MetricsSqlLeafResponse` — Arrow IPC bytes + stats + errors
- `MetricsSqlLeafError` — Per-split error information

**Reference existing patterns:**
- `LeafSearchRequest` in `search.proto` for split passing
- `SplitIdAndFooterOffsets` for split references

### Task 2: Add to build system

Update the proto build configuration to include the new file.

**File:** `quickwit/quickwit-proto/build.rs`

**Changes:**
- Add `protos/quickwit/metrics_sql.proto` to the compilation list
- Ensure it imports `search.proto` for `SplitIdAndFooterOffsets`

### Task 3: Generate Rust code

Run the build to generate Rust code from protobuf.

**Verify:**
- Generated structs in `src/codegen/quickwit/quickwit.metrics_sql.rs`
- Types are accessible from `quickwit_proto::metrics_sql`

### Task 4: Create Rust module wrapper

Create a clean Rust module interface for the generated types.

**File:** `quickwit/quickwit-proto/src/metrics_sql/mod.rs`

**Contents:**
- Re-export generated types
- Add any helper methods (e.g., `new()` constructors)
- Document the types

## Acceptance Criteria

- [ ] `metrics_sql.proto` exists with `MetricsSqlLeafRequest`, `MetricsSqlLeafResponse`, `MetricsSqlLeafError`
- [ ] Proto compiles without errors
- [ ] Rust types accessible via `quickwit_proto::metrics_sql`
- [ ] Request includes: sql, splits, index_uid, max_rows, timeout_ms
